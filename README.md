# APT repository

This repository is generated by [simit](https://codeberg.org/caniko/simit) and served at <https://apt.modde.tartanoglu.com>.

The `pages` branch contains the reprepro database and public package files. Release automation publishes signed packages here; the Pages workflow deploys `dists/`, `pool/`, and `key.gpg.asc`.

Configure Debian clients with:

```text
deb [signed-by=/etc/apt/keyrings/apt-repository.gpg] https://apt.modde.tartanoglu.com stable main
```
