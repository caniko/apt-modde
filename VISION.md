# apt-modde vision

A signed APT repository for the `modde` host, generated by
[simit](https://codeberg.org/caniko/simit) and served at
<https://apt.modde.tartanoglu.com>. The `pages` branch is the repository
database plus the public files: `conf/distributions` declares one suite
(`stable`, `main`, `amd64`), `dists/` and `pool/` hold the published index and
packages, and `key.gpg.asc` is the signing key clients pin.

It exists so Debian clients can install modde packages with ordinary APT
semantics instead of copying `.deb` files around:

```text
deb [signed-by=/etc/apt/keyrings/apt-repository.gpg] https://apt.modde.tartanoglu.com stable main
```

## Scope

- The reprepro database and published package tree.
- The Pages deployment that publishes `dists/`, `pool/` and `key.gpg.asc`,
  driven by a simit-generated GitHub workflow on pushes to `pages`.
- A prettier-only treefmt configuration for the Markdown and YAML that the
  repository does contain.

## Non-goals

The repository holds no source code, no packaging logic and no release tooling.
Release automation publishes signed packages here; building them happens
elsewhere. Manual edits to the generated workflow are reported as CI drift.
